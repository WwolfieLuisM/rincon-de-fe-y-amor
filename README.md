# Rincón de Fe y Amor 💒

Una **Progressive Web App** diseñada para que las parejas fortalezcan su vida espiritual juntos. Creada con ❤️ por Luismi.

🌐 **App:** [wwolfieluism.github.io/rincon-de-fe-y-amor](https://wwolfieluism.github.io/rincon-de-fe-y-amor/)

---

## ✨ Funcionalidades

| Módulo | Descripción |
|---|---|
| 🙏 **Oraciones** | Creen y lleven sus peticiones en pareja. Marcan juntos cada día como "orado" y el progreso avanza solo cuando ambos participan. |
| 🔥 **Racha de oración** | Lleven un registro diario. Escudos de protección para no perder la racha. Hitos y confetti al alcanzar metas. |
| 📖 **La Palabra** | Biblia integrada con todos los libros y capítulos. Selecciona versículos sin crashear en móvil. |
| 🌅 **Devocional diario** | Devocional para la mañana, tarde y noche. Versículo del día. |
| 🎯 **Metas compartidas** | Fijen metas espirituales como pareja. Sigan el progreso juntos en tiempo real. |
| 📅 **Fechas especiales** | Aniversarios, cumpleaños y fechas importantes con cuenta regresiva. |
| 💬 **Testimonios** | Escriban y compartan cómo Dios obra en su relación. |
| 💌 **Chat de ánimo** | Mensajes de aliento entre ustedes. |
| 🔔 **Notificaciones** | Recordatorios para orar juntos. Push notifications con Firebase. |

---

## 🛠️ Stack técnico

| Tecnología | Uso |
|---|---|
| Vanilla JS + CSS | Sin frameworks ni bundlers |
| Supabase | Base de datos PostgreSQL + Autenticación + Realtime |
| Firebase Cloud Messaging | Notificaciones push |
| GitHub Pages | Hosting estático |
| Service Worker | PWA offline support |
| Tabler Icons | Sistema de iconos |

---

## 🚀 Empezar

1. Abre [la app](https://wwolfieluism.github.io/rincon-de-fe-y-amor)
2. Regístrate con tu correo
3. Comparte el código de invitación con tu pareja
4. ¡Empiecen a orar juntos!

> 💡 **Tip:** Instala la app en tu celular desde el navegador para una experiencia completa.
